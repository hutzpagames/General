# Owner actions — one time only

1. Create a free Apify account and connect this GitHub directory as a new Actor.
2. Complete Apify billing details, KYC, and a Wise or PayPal payout method.
3. Publish the Actor to Apify Store.
4. In **Publication → Monetization**, choose **Pay per event**:
   - keep `apify-actor-start` at the default low price;
   - set `apify-default-dataset-item` to **$0.20** per result;
   - initially enable passing platform usage costs to users.
5. Run the default input once, verify the dataset, then publish version `1.0`.

After publication, discovery, execution, billing, API access, dataset delivery, analytics, and monthly payout generation are platform-managed. Payout invoice approval becomes automatic if ignored during the review window.
